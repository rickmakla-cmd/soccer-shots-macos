# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, private photographs, or local filesystem details in a public issue. Use the repository's private **Report a vulnerability** form under the **Security** tab. Include reproduction steps and impact, but redact API keys and personal data.

The Gemini API key belongs only in the app's Keychain-backed settings. It must never be committed to the repository or included in a diagnostic report.
